AI Processing State
Transitional screen between ask and result. Shows live 5-step progress pipeline: intent parsing → schema mapping → SQL generation → query execution → insight generation.
Transition
Layout structure
"Processing query…" + spinner + Cancel
sidebar 220px
question recap card
5-step progress pipeline
SQL preview (streaming)
Center column max-width 720px, auto margin. Focus on single task.
Step states
StepVisual
DoneGreen circle + checkmark. Green label. "Done" badge.
ActiveBlue spinner (rotating). Blue label + sub-text. "In progress" badge.
PendingGray empty circle. Muted text. 40% opacity row.
Components
Question recap card
Blue left-border card — 3px solid primary. Label "ANALYZING YOUR QUESTION" 11px uppercase.
Question text — 15px 600. Full question in quotes.
Step pipeline
Step icon — 28px circle. Colors per state (see layout). Spinner uses CSS animation.
Step title — 13px 500. Active step shows blue color.
Sub-text — 11px muted. Shows what was found or current action.
Status badge — Done (green) / In progress (blue) / Pending (gray).
Progress bar
Track — 5px height, full width, bg-secondary. Teal→blue gradient fill.
ETA text — 11px muted below bar. "Estimated 3–4 seconds remaining."
SQL preview
Streaming cursor — 8×14px block blinks at end of SQL. CSS animation steps(1).
Partial SQL — Tokens appear as generated. Same syntax colors as result screen.
States
Overall screen states
Step 1–2Intent + schema. Usually sub-1s. Appears briefly or may skip.
Step 3SQL generation. SQL preview block becomes visible with streaming text.
Step 4Query running. SQL preview locked. Spinner on progress bar.
Step 5Insight gen. "Generating insights…" sub-text. Nearly complete.
CompleteAll steps turn green. Auto-navigates to Result screen in 400ms.
TimeoutStep 4 turns red after 30s. Error card replaces progress. "Retry" + "Edit SQL".
Schema missStep 2 turns amber. "Table 'ordrs' not found — did you mean 'orders'?" inline.
